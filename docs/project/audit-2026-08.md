## A — Security and Privacy

### A1. Personal email in historical commit metadata

**Finding:** The email `joaobiel2004@gmail.com` appears as the author email on older commits (author name "João Gabriel"). It exists only in Git commit metadata, never in tracked file content.

**Evidence:**

```text
git log --all --format='%an|%ae' | sort -u
João Gabriel|joaobiel2004@gmail.com
joão gabriel|129410759+jotatw@users.noreply.github.com
google-labs-jules[bot]|161369871+google-labs-jules[bot]@users.noreply.github.com
```

A scan of `HEAD` file content for `[A-Za-z0-9._%+-]+@[A-Za-z0-9.-]+\.[A-Za-z]{2,}` returned **zero** matches. The email is not present in README, documentation, comments, configuration examples, or any tracked file.

**Severity:** Low.

**Action:** Document only. No history rewrite. Rewriting 161 commits in a public repository would add risk and break existing references without a compromised-secret indication. See [Known Accepted Risks](#known-accepted-risks).

**Status:** Documented.

### A3. YouTube API key via environment variable

**Finding:** The only credential the project consumes is the YouTube API key, read exclusively from `YOUTUBE_API_KEY` (with an optional local config file fallback). No hardcoded key exists.

**Evidence:**

- `melody-sync-desktop/src/main/kotlin/com/melodysync/desktop/state/AppState.kt:266` — `System.getenv("YOUTUBE_API_KEY")`
- `melody-sync-core/src/main/kotlin/com/melodysync/service/YouTubeSearchService.kt:27` — `apiKey: String` parameter, `require(apiKey.isNotBlank())`
- `scripts/install.sh:57` — documents the env var
- Scan for `password|secret|token|api_key` assignments across tracked files: only the env-var pattern and the fake test key.

**Severity:** Informational.

**Action:** None. Continue prevention (never commit keys; keep env-var based injection).

**Status:** Documented.

### A4. IDE configuration files tracked

**Finding:** Several IDE-specific files are tracked despite `.gitignore` rules for `.idea/` and `.vscode/`.

**Evidence:**

```text
git ls-files .idea .vscode
.idea/.gitignore
.idea/material_theme_project_new.xml   ← contains userId 1e6a2b67:19e566a7bd0:-7ffa
.idea/misc.xml                          ← stale "Python 3.14 (Melody-Sync)" SDK / Black config
.idea/vcs.xml
.vscode/settings.json                   ← stale Python analysis setting
```

The project migrated from Python to Kotlin (see ADR-0002/ADR-0003); the Python SDK and Black references in `.idea/misc.xml` and `.vscode/settings.json` are obsolete.

**Severity:** Low (no credentials; `userId` is a pseudonymous IDE identifier).

**Action:** Deferred to Pass B — Structure (tracked IDE artifacts). Decide whether to untrack/remove as repository hygiene.

**Status:** Deferred to B.

### B5. `app-design.md` naming ambiguity

**Finding:** Two unrelated documents share the basename `app-design.md`:
