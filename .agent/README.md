# Agent Notes

Esta pasta registra as decisões e planejamentos feitos em sessões com agentes de IA no desenvolvimento do Melody Sync.

## Propósito

- Preservar o contexto e as decisões tomadas em cada sessão.
- Registrar o estado do projeto em pontos específicos do tempo.
- Servir de referência para sessões futuras, evitando repetir trabalho.

## Estrutura

| Arquivo | Conteúdo |
|---------|----------|
| `session-001.md` | Sessão de migração para Kotlin (planejamento, ADRs, ambiente) |

## Convenções

- Um arquivo por sessão, no formato `session-NNN.md`.
- O conteúdo é um registro factual: contexto, decisões, resultados e pendências.
- Não duplicar documentação oficial: as decisões técnicas definitivas vivem em `docs/architecture/ADR/` e referências aqui apontam para lá.

## Relação com a documentação oficial

- `docs/` — documentação oficial (ADR, guias, jornais).
- `.agent/` — registro das interações com agentes (planejamento operacional).
